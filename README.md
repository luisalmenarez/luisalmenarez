I build web applications and automate the manual processes behind them. Four years working with **React, Next.js and TypeScript** on the frontend, **Node.js, SQL Server and n8n** on the backend and automation side — for companies in logistics, education, fintech and CRM.

Right now I work as a **Fullstack HubSpot Developer**, connecting CRM data to custom web tooling.

---

### 📈 Selected results

- ⚙️ Automated a commission liquidation process handling **200+ payees** and **57 versioned business rules**, including Colombian tax and social-security logic — cutting a multi-day manual close down to a single automated run.
- 🚚 Built **CloudFleetExtract**, a Node.js pipeline that ingests **51,000+ work orders** into SQL Server to feed Power BI dashboards, replacing recurring manual exports.
- 🧩 Shipped a reusable component library in Storybook that cut **development time by 30%** and improved **page load speed by 20%**.
- 🎓 Contributed to the **Universidad de los Andes digital ecosystem** (Drupal + Site Studio + Storybook) while at Esinergia.

### 🤖 Automation is half of what I do

Most of my value isn't a prettier UI — it's removing the spreadsheet in the middle.

- **n8n** workflows for business-critical processes: validation, calculation, scheduling, error recovery.
- **REST & GraphQL integrations** between CRMs, ERPs and internal systems.
- **SQL Server** procedures and data pipelines feeding BI dashboards.
- **HubSpot** custom development: field mapping, CRM data flows, internal tooling.
